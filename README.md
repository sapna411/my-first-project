# My First Python Project 🐍

## About
This is my first Python practice project, created while learning Python programming, Git and GitHub.

The project demonstrates basic Python output and user input.

## Features
- Displays a welcome message.
- Takes the user's name as input.
- Prints a personalised greeting.

## Technologies Used
- Python 3.14
- Visual Studio Code
- Git and GitHub

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
py hello.py
```
